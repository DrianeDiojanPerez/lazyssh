# Updating

```
lazyssh --update
```

It downloads the installer and runs it, so the update lands in the same place the first install did. If you already have the newest version, the installer says so and asks before installing it again.

`lazyssh --version` prints the version you have.

On Windows, `--update` isn't supported yet. It prints the link to the newest release, and you replace `lazyssh.exe` by hand.

Close lazyssh before updating. Open tabs are closed with it.
