# Settings and themes

Press `s` for settings. Every change is saved right away in `~/.config/ssh-manager/theme.json`.

| Setting | What it does |
|---|---|
| Ask every time / Open in a tab / Take the whole terminal | How `Enter` opens a connection. See [How it works](how-it-works.md#opening-a-connection) |
| Theme | Opens the theme picker, same as `t` |
| Transparency | Lets your terminal's own background show through, same as `T` |
| Slanted tabs | Slanted edges on the tabs |
| Tabs in a panel | Draws the tabs in their own panel |
| Connecting screen | Shows a screen while a connection is being made |

## Themes

Press `t`, move with `↑` `↓`, and press `Enter`. `Esc` goes back without changing anything.

The themes are Transparent, Tokyo Night, Catppuccin Mocha, Dracula, Nord, Gruvbox Dark, and Cyberpunk. Transparent uses your terminal's own colors and background.
